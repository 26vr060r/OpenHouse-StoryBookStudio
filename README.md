# StoryBook Studio

見開き24ページ（左・插絵／右・文章）の絵本を、ブラウザでつくる HTML アプリです。ビルドは不要です。

## アプリで今できること / まだできないこと

**今できること（Sprint 03）**

- テーマや登場人物などの条件を選ぶ
- 「おまかせで一冊」で見本条件から物語を組む
- 見開き12（24ページ）の文章を、左右キー・ボタン・スワイプでめくる
- 横書き／縦書き、ふりがな（ruby）
- `?studio=1` で intent と非表示 Bible を確認する

**まだできないこと**

- 插絵の生成（Sprint 04 デモ、Sprint 08 Gemini）
- プロンプトの書き出し（Sprint 05）
- 種類別フォルダへの保存（Sprint 06）
- 印刷・PDF（Sprint 07）

左ページはプレースホルダです。キャラの色・身長アンカー（Bible）はユーザ画面には出しません。

## 開き方

1. このリポジトリをクローンする（またはフォルダを開く）
2. `app/index.html` をブラウザで開く（ダブルクリックで可）
3. 展示キオスクにするときは `app/index.html?kiosk=1`（運営者の歯車を隠す）
4. 入力内容と Bible を見るときは `app/index.html?studio=1`

ウィザードと見開きビューアは `file://` で動きます。

## フォルダ

- `app/` … アプリ本体
- `templates/prompts/` … プロンプトレシピ（Sprint 05 で中身を追加）
- `library/` … 絵本の成果物ルート。命名規約は [library/README.md](library/README.md)

## 開発の進め方

1日スプリントです。作業ブランチは `sprint/03-story` のように切り、終わりに `main` へ PR します。絵本コンテンツの量産ではなく、**アプリの機能を載せる**計画です。
