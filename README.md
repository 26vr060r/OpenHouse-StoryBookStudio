# StoryBook Studio

見開き24ページ（左・插絵／右・文章）の絵本を、ブラウザでつくる HTML アプリです。ビルドは不要です。

## アプリで今できること / まだできないこと

**今できること（Sprint 04）**

- テーマや登場人物などの条件を選ぶ
- 「おまかせで一冊」で、色と身長が揃ったデモ插絵つきの見開きを読む
- 12見開きを、左右キー・ボタン・スワイプでめくる
- 横書き／縦書き、ふりがな
- `?studio=1` で intent と非表示 Bible を確認する

**まだできないこと**

- プロンプトの書き出し（Sprint 05）
- 種類別フォルダへの保存（Sprint 06）
- 印刷・PDF（Sprint 07）
- Gemini による本插絵（Sprint 08）

插絵はアプリ内のキャラキットです。同じパレットと地面アンカーを全ページで使います。

## 開き方

1. このリポジトリをクローンする（またはフォルダを開く）
2. `app/index.html` をブラウザで開く（ダブルクリックで可）
3. 展示キオスクにするときは `app/index.html?kiosk=1`
4. 入力内容と Bible を見るときは `app/index.html?studio=1`

デモ插絵までは `file://` で動きます。

## フォルダ

- `app/` … アプリ本体
- `templates/prompts/` … プロンプトレシピ（Sprint 05 で中身を追加）
- `library/` … 絵本の成果物ルート。命名規約は [library/README.md](library/README.md)

## 開発の進め方

1日スプリントです。作業ブランチは `sprint/04-demo-art` のように切り、終わりに `main` へ PR します。絵本コンテンツの量産ではなく、**アプリの機能を載せる**計画です。
