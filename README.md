# StoryBook Studio

見開き24ページ（左・插絵／右・文章）の絵本を、ブラウザでつくる HTML アプリです。ビルドは不要です。

## アプリで今できること / まだできないこと

**今できること（Sprint 06）**

- テーマや登場人物などの条件を選ぶ
- 「おまかせで一冊」で、色と身長が揃ったデモ插絵つきの見開きを読む
- 12見開きを、左右キー・ボタン・スワイプでめくる
- 「この絵本を保存」で種類別フォルダ構造の `{bookId}.zip` を出す（書庫にも残る）
- Chrome / Edge の http では、歯車から `library` を選んでフォルダへ直書きできる
- 「書庫をひらく」から保存した絵本を開き直す
- 作成を中止した絵は、ホームの「つづきから」で再開できる
- `?studio=1` で intent、Bible、プロンプトを確認する

**まだできないこと**

- 印刷・PDF・見開きPNG書き出し（Sprint 07）
- Gemini による本插絵（Sprint 08）

插絵はアプリ内のキャラキットです。同じパレットと地面アンカーを全ページで使います。

## 開き方

1. このリポジトリをクローンする（またはフォルダを開く）
2. `app/index.html` をブラウザで開く（ダブルクリックで可）
3. 展示キオスクにするときは `app/index.html?kiosk=1`
4. 入力・Bible・プロンプトを見るときは `app/index.html?studio=1`

デモ插絵・ZIP・ブラウザ内書庫は `file://` で動きます。フォルダ直書きは Chromium 系で http（Cursor プレビューや `python -m http.server`）が必要です。保存先はリポジトリの `library/` を選んでください。

## フォルダ

- `app/` … アプリ本体
- `templates/prompts/` … プロンプトレシピ（穴あき文面。実行時は `app/js/prompt-templates.js`）
- `library/` … 絵本の成果物ルート。命名規約は [library/README.md](library/README.md)

## 開発の進め方

1日スプリントです。作業ブランチは `sprint/06-library` のように切り、終わりに `main` へ PR します。絵本コンテンツの量産ではなく、**アプリの機能を載せる**計画です。
