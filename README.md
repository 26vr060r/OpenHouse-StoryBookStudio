# StoryBook Studio

見開き24ページ（左・插絵／右・文章）の絵本を、ブラウザでつくる HTML アプリです。ビルドは不要です。

## アプリで今できること / まだできないこと

**今できること（Sprint 05）**

- テーマや登場人物などの条件を選ぶ
- 「おまかせで一冊」で、色と身長が揃ったデモ插絵つきの見開きを読む
- 12見開きを、左右キー・ボタン・スワイプでめくる
- 横書き／縦書き、ふりがな
- 入力をプロンプト成果物に変換する（bookId・共有ロック・ページ別）
- 「プロンプトを保存」で `prompt/{bookId}/` 構造の ZIP を出す
- `?studio=1` で intent、Bible、各見開きのプロンプトを確認する

**まだできないこと**

- 種類別フォルダへの保存・再読込（Sprint 06）
- 印刷・PDF（Sprint 07）
- Gemini による本插絵（Sprint 08）

插絵はアプリ内のキャラキットです。同じパレットと地面アンカーを全ページで使います。プロンプトは次の Gemini 連携用で、このスプリントでは文面だけを作ります。

## 開き方

1. このリポジトリをクローンする（またはフォルダを開く）
2. `app/index.html` をブラウザで開く（ダブルクリックで可）
3. 展示キオスクにするときは `app/index.html?kiosk=1`
4. 入力・Bible・プロンプトを見るときは `app/index.html?studio=1`

デモ插絵とプロンプトZIPまでは `file://` で動きます。

## フォルダ

- `app/` … アプリ本体
- `templates/prompts/` … プロンプトレシピ（穴あき文面。実行時は `app/js/prompt-templates.js`）
- `library/` … 絵本の成果物ルート。命名規約は [library/README.md](library/README.md)

## 開発の進め方

1日スプリントです。作業ブランチは `sprint/05-prompts` のように切り、終わりに `main` へ PR します。絵本コンテンツの量産ではなく、**アプリの機能を載せる**計画です。
