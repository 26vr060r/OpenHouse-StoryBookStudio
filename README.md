# StoryBook Studio

見開き24ページ（左・插絵／右・文章）の絵本を、ブラウザでつくる HTML アプリです。ビルドは不要です。

## アプリで今できること

**今できること（Sprint 09）**

- テーマや登場人物などの条件を選ぶ
- 「おまかせで一冊」で、色と身長が揃ったデモ插絵つきの見開きを読む
- 運営者が API キーを入れると、Gemini で参照シートと 12 枚の插絵（必要なら文章）を順に作る
- キーなし・`file://`・失敗したページは、同じキャラキットのデモ插絵に落とす
- 開いている見開きだけ「この絵を描き直す」（他のページは触らない）
- 生成の中止と、途中からの再開
- 12見開きを、左右キー・ボタン・スワイプでめくる（タブレット縦向きは1画面1ページ）
- 「この絵本を保存」で種類別フォルダ構造の `{bookId}.zip` を出す
- 「印刷する」で A4横の見開き、または製本用の A5×24ページを出す
- 書庫からの再オープン

插絵の透かし（SynthID）は消しません。印刷用フォント（Noto Sans JP / Noto Serif JP、OFL）をアプリに同梱しています。

## 来場者向け

展示キオスクでは、設定の歯車は出ません。

1. `app/index.html?kiosk=1` を全画面で開く（タブレットならホーム画面に追加してもよい）
2. 「絵本をつくる」か「おまかせで一冊」を押す
3. 待ち画面では「あと○ページ」と出ます。中止すると、途中まで残ります
4. 左が絵、右が文です。横向きは見開き、縦向きは1ページずつ
5. 気に入らない插絵は「この絵を描き直す」（ほかのページはそのまま）
6. 「この絵本を保存」で ZIP を持ち帰れます

キーが入っていれば Gemini の絵、入っていなければデモの絵です。どちらもキャラの色と身長は全ページでそろえます。実在の子どものフルネームや住所は書かないでください。

## 運営者向け

1. このリポジトリをクローンする（またはフォルダを開く）
2. Gemini を使うときは **http** で開く（Cursor プレビューや `python -m http.server`）。`file://` だとデモと ZIP だけです
3. 右上の歯車で **Gemini API キー** を入れる。キーは `localStorage` のみで、ZIP や Git には入りません
4. 插絵の作り方: 自動 / いつもデモ / 必ず Gemini
5. 展示は `app/index.html?kiosk=1`（歯車も `?studio=1` も出さない）
6. 入力・Bible・プロンプトを見るときは `app/index.html?studio=1`（キオスク中は無効）
7. Chrome / Edge なら、歯車から `library` フォルダを選ぶと直書きできます
8. 「この絵を描き直す」は今開いている見開きだけ。失敗したら前の絵を残す

文章は `gemini-2.5-flash`、插絵は `gemini-3.1-flash-image`（失敗時は近縁モデルへ）。safety 設定を付け、参照シートを先に1枚作ってから 12 ページへ添付します。レート制限のため順次呼び出しです。

## 開き方

1. このリポジトリをクローンする（またはフォルダを開く）
2. `app/index.html` をブラウザで開く（ダブルクリックで可。その場合はデモ插絵）
3. 展示キオスクにするときは `app/index.html?kiosk=1`
4. 入力・Bible・プロンプトを見るときは `app/index.html?studio=1`

## PDF と印刷

ブラウザの印刷ダイアログで「横」を選んでも、PDF が縦になってしまうことがあります。用紙サイズを確実に固定するには、印刷画面の **PDFを保存** を使ってください。奥付（つくった日と bookId）は画面の最終見開きにだけ出し、印刷と PDF には入れません。

### 見開き（家庭用・A4横）

1. 絵本を開き、「印刷する」
2. 「見開き（A4横）」を選ぶ
3. **PDFを保存** を押す（ファイル名の例: `{bookId}.print-a4.pdf`）
4. 保存先は `library/pdf/` にすると規約と揃います

紙に出すときも、同じ画面の「印刷する」が使えます。プリンタ側の用紙は A4、向きは横です。

### 製本／小冊子（プリンタの製本印刷）

本文を **A5縦×24ページ**（左の絵、右の文、を交互）の PDF にします。プリンタの「製本」「小冊子」が、A4両面に2ページずつ面付けします。

1. 印刷画面で「製本用（A5×24ページ）」を選ぶ
2. **PDFを保存**（`{bookId}.booklet.pdf`）
3. プリンタの印刷設定で **製本** または **小冊子** を選ぶ
4. 用紙は **A4**、印刷は **両面**、とじ方向は機種の「短辺とじ／左とじ」に合わせる
5. 出来上がりは A5 サイズの24ページです

ZIP 内の `html/{bookId}.print-a4.html` と `html/{bookId}.print-booklet.html` はプレビュー用です。PDF の向きは HTML 経由より、「PDFを保存」の方が確実です。

## フォルダ

- `app/` … アプリ本体（`app/fonts/` に Noto を同梱）
- `templates/prompts/` … プロンプトレシピ
- `library/` … 絵本の成果物ルート。命名規約は [library/README.md](library/README.md)

## 開発の進め方

1日スプリントです。作業ブランチは `sprint/09-redraw` のように切り、終わりに `main` へ PR します。絵本コンテンツの量産ではなく、**アプリの機能を載せる**計画です。
