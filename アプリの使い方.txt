リポジトリ直下の **アプリを起動**（バッチまたはショートカット）をダブルクリックすると、サーバを立てて `http://127.0.0.1:8080/` を開きます。歯車を隠す展示は **アプリを起動_キオスク** です。起動した黒い窓は閉じないでください。

PowerShell は「黒い（または青い）文字入力の窓」です。サーバを立てているあいだは、この窓を閉じないでください。手動で起動する手順は次のとおりです。

## 1. PowerShell を開く

1. キーボードの Windows キーを押す  
2. `powershell` と入力する  
3. **Windows PowerShell** または **PowerShell** を開く  

管理者として実行する必要はありません。

## 2. アプリのフォルダへ移動する

次をコピーして、PowerShell に貼り付け、Enter を押します。

```powershell
cd "C:\■研究\Cursor\20260917_OpenHouse_StoryBookStudio\app"
```

うまくいったか確認します。

```powershell
dir
```

`index.html` という名前が見えれば正解です。  
「指定されたパスが見つかりません」と出たら、エクスプローラーで `app` フォルダを開き、アドレスバーをクリックしてパスをコピーし、`cd "コピーしたパス"` でもう一度試してください。

## 3. サーバを起動する

まず Python を試します。

```powershell
python -m http.server 8080
```

`Python が見つかりません` や `python は認識されません` と出たら、次を試します。

```powershell
py -m http.server 8080
```

それでもダメなら、Node 側です。

```powershell
npx --yes serve -l 8080
```

成功すると、窓に `Serving HTTP on ... 8080` のような英文が出て、**そのまま止まります。** それは故障ではなく、サーバが動いている印です。この窓は閉じません。

止めるときは、その窓をクリックして **Ctrl + C** を押し、確認が出たら `Y` を押します。

## 4. ブラウザで開く

Chrome か Edge のアドレスバーに、次を入力して Enter します。

```
http://127.0.0.1:8080/
```

先頭が `http://` であることを確認します。`file://` のままだと失敗です。

ホームの「いまの設定」で、通信が **送れます（http）** になっていれば成功です。  
`file://` のときに入れたキーは引き継がれないことがあるので、右上の歯車で Gemini APIキーをもう一度貼ってください。

展示用に歯車を隠すときは、次です。

```
http://127.0.0.1:8080/index.html?kiosk=1
```

## うまくいかないとき

- **ポートが使われています**  
  `8080` を `8081` に変えて起動し、ブラウザも `http://127.0.0.1:8081/` にします。  
- **ページが白い／出ない**  
  `dir` で `index.html` があるフォルダから起動しているか確認します。リポジトリの一番上から起動した場合は `http://127.0.0.1:8080/app/` です。  
- **python も npx もない**  
  Cursor で `app/index.html` を開き、プレビュー（簡易サーバ）で表示する方法でも同じです。アドレスが `http://` で始まればよいです。






## Gemini APIキーの取り方と入れ方

キーは、Googleの「AI Studio」で発行します。Googleアカウント（大学Gmailでも個人Gmailでも可）が必要です。

1. Chrome か Edge で [Google AI Studio の APIキーページ](https://aistudio.google.com/apikey) を開く  
2. Googleアカウントでログインする  
3. 利用規約が出たら読む。問題なければ同意する  
4. **Create API key**（APIキーを作成）を押す  
5. プロジェクトを選ぶ（初めてなら「新しいプロジェクトを作る」でよい）  
6. 表示されたキーをすぐコピーする。あとから全部は見えないことがある  
7. キーはパスワードと同じ。チャット、メール、GitHub、ZIPには貼らない  

插絵モデル（`gemini-3.1-flash-image`）は無料枠では使えません。初めて課金するときは、AI Studio の **Set up billing** から支払い方法を登録します（Google側で最低チャージがある場合があります）。試し作りは歯車で **Lite** にすると安くなります。3.1系は 0.5K（512）。2.5 Flash Image だけ公式が 1K 固定です。見開き12ページなら、本番0.5Kでおおよそ数十円、24ページならおおよそ100円前後が目安です。

### このアプリへの入れ方

1. アプリは **http で開く**（Cursorのプレビュー、またはフォルダで `python -m http.server`）。エクスプローラーから `index.html` をダブルクリック（`file://`）すると、キーを入れても Gemini には送れません  
2. 右上の **⚙** を押す  
3. 「Gemini APIキー」に貼る  
4. 「插絵の作り方」は、最初は **自動（キーがあれば Gemini、なければデモ）** のままでよい  
5. 画質は、本番なら `gemini-3.1-flash-image（0.5K）`、試しなら 3.1 Lite（0.5K）または 2.5 Flash Image（1K・公式固定）  
6. **とじる**  
7. ホームの「いまの設定」で、APIキーが「入っています」、通信が「送れます（http）」なら成功です  

キーはこのブラウザの中だけに残ります。ZIPやGitには入りません。他人のPCや展示キオスク（`?kiosk=1`）では歯車が出ないので、運営者が先に入れておきます。

## 絵本のつくり方（初見向け）

StoryBook Studio（世界に一つだけの絵本）は、左が絵・右が文の絵本をブラウザでつくるアプリです。キーがなくても「デモ插絵」（色と形をそろえた簡易絵）で一冊作れます。キーがあると Gemini が絵（と必要なら文章）を描きます。

### 0. 開く
- 普段の作業: `app/index.html` を http で開く  
- 展示だけ見る: `app/index.html?kiosk=1`（歯車は出ない）

### 1. ホームで長さと画質を確認する
画面下の「いまの設定」を見る。  
ページ数は歯車で **見開き12／16／20／24**（初期は12）。左綴じ。12ページなら表紙1＋本文見開き5つ＋裏表紙1です。

### 2. つくり始める
- **絵本をつくる** … 条件を自分で選ぶ（おすすめ）  
- **おまかせで一冊** … 押すたびに、別の物語の種（題名・登場人物・きっかけ）で一冊つくる  
- **書庫をひらく** … 前に保存した本を開く。一覧または絵本画面でタイトルを直して **タイトルを保存** できる。開いたあと **工程に戻る** で、指定から文章確認、キャラクター6面図（正面・後方・左・右・上・下）まで見直せる  

実在の子どものフルネームや住所は書かないでください。

### 3. 条件を選ぶ（4ステップ）
各項目は、チップを押すか「自分で書く」か、**どちらか1つ**です。

1. テーマ、だれ向け、おはなしの型。対象年齢ごとの本文の長さは、以前の基準の1.5倍です。2〜6歳は本文をひらがな、7〜9歳は小学校低学年の漢字、10〜12歳は小学校高学年までの漢字、13〜15歳は中学校までの漢字、おとなと一緒には日常の漢字で書きます  
2. 舞台、絵の雰囲気、横書き／縦書き、ふりがな（はじめはオフ。7歳以上でオンなら絵本の右ページで漢字にルビを付ける。確認欄には（ふりがな）を書かない。2〜6歳はオンでも漢字は使わない。字数は漢字だけ）  
3. 登場人物（目安3人、上限5人）。主人公は1人。せいかくは3つまで。とくちょうを書かないときは、対象年齢に合う見た目でキャラクターデザインをつくります。各登場人物は顔・髪・服・シルエットが違うようにします（作者が双子と書いたときだけ似せます）。6面図の絵のタッチは一冊でそろえます（キャラごとに別の画風にはしません）  
4. タイトルを確認して **この条件でつくる**

### 4. 待つ
「あと○ページ」と出ます。枚数が多いほど時間がかかります。  
**中止**すると途中まで残ります。ホームの **つづきから** で再開できます。  
文章はステップ4までの指定（題名・テーマ・舞台・雰囲気・読者・登場人物・話の形・作者メモ）だけを材料に、ゼロから発明します。スタジオのページ計画や下書き、過去の絵本は送りません。題名も「だれのテーマ」の定番にはせず、本文ができたあとにその本だけの題名へ直します。表紙と裏表紙は插絵だけで文章を載せられないため、シナリオは表紙を除いた奇数ページだけ（見開き12なら3・5・7・9・11ページ）で設計します。偶数ページは插絵です。終わりのできごとは最後の奇数ページに書き、裏表紙には物語を書きません。表紙の題名はフッターだけです。さく・えやオリジナルさっかは書きません。文章確認で直した右ページは、そのあと描く左ページの插絵の内容になります。  
1枚の插絵に出す登場人物は、本文またはページ計画に名前がある人から最大3人まで。名前がなければ人物は入れません。同じキャラクターを二人以上描くことは、物語が分身・残像・変身の前後などと書いていない限りありません（6面図は一人の参照であり、插絵に並べません）。人の体を不自然に折り曲げる描き方はしません。挿絵の中にセリフの吹き出し、擬音、状況説明の文字は入れません。右ページの文章は絵の意味だけに使い、画像には書きません。持ち物・目印の建物・空や地面・名前のない人など、指定キャラ以外の見た目と色もページごとに変えません。

### 5. 読む
- 横向き: 左が絵、右が文。右ページの文章は、改行と文字の大きさで見開きにおさまるように整えます  

- 縦向き（タブレット）: 1画面1ページ  
- **まえ／つぎ**、左右キー、スワイプでめくる  
- **書庫をひらく** で保存したほかの本の一覧へ戻る  
- 絵だけ直したいときは、その見開きで **この絵を描き直す**（他のページは変わりません）

### 6. 持ち帰る
- **この絵本を保存** … ZIP をダウンロード  
- **印刷する** … 印刷画面から **絵本へ** / **ホームへ** / **書庫をひらく** にも戻れる  
  - 家庭用: 「見開き（A4横・左綴じ）」→ **PDFを保存**（最初の1枚は左が裏表紙・右が表紙。題名は表紙フッター）  
  - 製本: 「製本用（A5×この本のページ数・左綴じ）」→ **PDFを保存** → プリンタの「製本／小冊子」（1ページ表紙、偶数插絵、奇数文章、最後が裏表紙）  
- ブラウザの「PDFに保存」だと向きが縦になることがあるので、アプリの **PDFを保存** を使う  

ディスクの `library` フォルダへ直書きしたいときだけ、歯車の「保存先フォルダ」でリポジトリの `library` を選びます。選ばなくても ZIP は出せます。

迷ったら、キーなしで「おまかせで一冊」を一度作り、めくって保存まで試すと全体がわかります。
